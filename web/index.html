《轮回失格》

无限流 / 规则怪谈 / 群像成长。主角：秦川。第一副本：七号教学楼。

怎么用

你只要点按钮，或者按数字键选择。

  1. 1续写下一章：按 2000-2500 字一章推进。
  2. 2改设定：主角、书名、职业、规则都能继续换。
  3. 3看大纲：先看每章发生什么，再决定写哪章。
  4. 4润色检查：检查悬念、节奏、爽点和恐怖感。

核心钩子

秦川第三次睁眼时，自己的尸体挂在教室门口。

他每次死亡都会回到副本开局，但会保留疼痛、记忆和精神污染；若改变副本角色命运，对方可成为拥有循环记忆的同伴。
